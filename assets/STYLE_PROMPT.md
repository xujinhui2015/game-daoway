# Daoway 图像素材统一风格前缀

所有 gpt-image-2 素材都以以下中文前缀开头，再追加具体主体描述：

> 水墨像素国风游戏素材，低饱和宣纸色调，松烟墨线条，细腻纸纹背景，像素块清晰但边缘有轻微墨晕，东方留白，克制朱砂点缀，只使用宣纸、松烟墨、朱砂、黛青、苔绿、赭石及其明度变化；避免欧美卡通像素 RPG 高饱和描边，避免霓虹，避免厚重 3D，避免写实摄影，避免文字、水印、logo。

## 尺寸与命名

- 场景背景：`assets/generated/scenes/*.png`，宽屏，接主视图。
- 角色立绘：`assets/generated/portraits/*.png`，竖版，接主界面/家庭/事件。
- 门派标识：`assets/generated/sects/*.png`，方形或横幅，接门派界面。
- 事件配图：`assets/generated/events/*.png`，横向插画，接渡劫/婚育/奇遇/飞升。
- 图标：`assets/generated/icons/*.png`，方形，接造化阁、功法、装备、丹药、货币。
- UI 纹理：`assets/generated/ui/*.png`，可平铺纸纹、卷轴轴头、朱砂印模板。

## 样张自检

- 色温是否低饱和。
- 是否有宣纸纹理与松烟墨线。
- 朱砂是否只作为少量点缀。
- 是否仍像像素游戏素材，而不是普通国风插画。
- 是否没有文字、水印、现代物件和版权形象。
